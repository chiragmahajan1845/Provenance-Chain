# ProvenanceChain: Blockchain-Based Supply Chain Provenance & Counterfeit Detection

**Author:** Chirag Mahajan (Roll No: 2025A1R095 | Third Sem, Section A4)

## Project Overview
ProvenanceChain records each stage of a physical product's journey as an immutable event on-chain using Solidity smart contracts and Polygon L2 architecture.

- **Smart Contract:** Solidity (`contracts/ProvenanceChain.sol`)
- **Backend & Ingestion:** Python & `web3.py`
- **Frontend & Verification:** Streamlit (`app.py`)
- **Dataset:** Simulated logistics milestones based on the DataCo Smart Supply Chain dataset
